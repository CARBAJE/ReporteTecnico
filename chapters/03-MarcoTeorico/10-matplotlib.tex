\section{Matplotlib}

\subsection{Introducción}%
\label{subsec:introduccion}
Matplotlib es la biblioteca base de visualización 2D (y 3D básico) del ecosistema científico de Python. Permite generar figuras estáticas, animadas e interactivas con calidad de publicación, integrándose de forma natural con NumPy/SciPy/pandas y adoptando una interfaz familiar para usuarios de MATLAB~\cite{Hunter2007, VanderPlas2016, MatplotlibDevTeamMain, ActiveStateMatplotlib}. Su adopción generalizada en investigación respalda su estabilidad y evolución~\cite{MatplotlibDevTeamMain}.

\subsection{Arquitectura y conceptos clave}%
\label{subsec:arquitectura}
Matplotlib separa responsabilidades en tres capas~\cite{Jones2012Matplotlib, delftswaMatplotlib}:
\begin{enumerate}
  \item \textbf{Backend}\footnote{Backend: motor de render y salida (pantalla/archivo). Común: Agg (raster), PDF/SVG (vectorial).}: gestiona renderizado y salida a formatos/ventanas (Tk/Qt/wx/GTK o archivos PNG, PDF, SVG).
  \item \textbf{Artist (núcleo)}: jerarquía de objetos que componen la figura (Figure, Axes\footnote{\texttt{Axes}: área de trazado con ticks/labels/leyendas.\ \texttt{Axis}: el eje numérico en sí.}, líneas, textos, parches).
  \item \textbf{Capa \texttt{pyplot}}: interfaz de alto nivel con estado para trazados rápidos~\cite{MatplotlibDevTeamPyplotTut}.
\end{enumerate}

\subsection{Capacidades de trazado y personalización}%
\label{subsec:caracteristicas_trazado}
Soporta líneas, dispersión, barras, histogramas, contornos y mapas de calor; 3D básico con \texttt{mplot3d}~\cite{VanderPlas2016}. Ofrece control detallado (colores, estilos, tipografías, anotaciones) y múltiples formatos de salida (PNG;\ PDF/SVG vectoriales para publicación)~\cite{GeeksforGeeksIntroMPL, Jones2012Matplotlib, Zhauniarovich2022}. Permite animaciones (\texttt{FuncAnimation}) para procesos dependientes del tiempo~\cite{llegodev2023}.

\subsection{Aplicaciones típicas}%
\label{subsec:aplicaciones}
En física/astro/ingeniería se usa para trayectorias, espacios de fase, campos y series temporales~\cite{VanderPlas2016, Landau2015, RealPythonAstro}. En IA/ML:\ curvas de entrenamiento (loss/accuracy), matrices de confusión, ablation studies, \emph{hyperparameter sweeps} y visualización de inferencia. Es base de librerías de mayor nivel como Seaborn~\cite{Waskom2021} y se integra con Jupyter para flujos reproducibles~\cite{VanderPlas2016, SciPyLecturesEcosystem}. Casos emblemáticos incluyen visualizaciones del EHT y misiones de la NASA~\cite{EHT2019, delftswaMatplotlib}.

\subsection{Ventajas}%
\label{subsec:ventajas}
\begin{itemize}
  \item \textbf{Versatilidad}: amplio catálogo 2D y control fino de la estética~\cite{GeeksforGeeksIntroMPL, Vu2023}.
  \item \textbf{Calidad de publicación}: salida vectorial (PDF/SVG) y estilos configurables (\texttt{rcParams}, hojas de estilo; p.\,ej., SciencePlots)~\cite{Hunter2007, MatplotlibDevTeamCustomizing, GarrettSciencePlots}.
  \item \textbf{Ecosistema}: integración estrecha con NumPy/SciPy/pandas y soporte multiplataforma~\cite{VanderPlas2016, Jones2012Matplotlib}.
  \item \textbf{Abierto y documentado}: comunidad amplia y documentación extensa~\cite{MatplotlibDevTeamMain, MatplotlibDevTeamQuickStart}.
\end{itemize}

\subsection{Limitaciones}%
\label{subsec:limitaciones}
\begin{itemize}
  \item \textbf{Verbosidad y curva inicial}: figuras complejas requieren API OO y más código; la dualidad \texttt{pyplot}/OO puede confundir~\cite{Vu2023, RedditBioinfoMatplotlibSucks}.
  \item \textbf{Rendimiento con datos muy grandes}: millones de puntos pueden requerir muestreo, agregación o librerías alternativas~\cite{StackOverflowGnuplotMPL}.
  \item \textbf{Interactividad limitada web}: menor que soluciones web nativas (Plotly/Bokeh)~\cite{GeeksforGeeksIntroMPL}.
\end{itemize}
