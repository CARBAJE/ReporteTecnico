\section[FrameworkQt \& PyQt]{Framework de interfaz: Qt \& PyQt}

\subsection{Introducción a Qt}
Qt es un framework C/C99 multiplataforma para construir GUIs y apps nativas en Linux, Windows, macOS, Android y sistemas embebidos, bajo el principio “escribe una vez, ejecuta en múltiples plataformas”\footnote{WORA:\ escribir una sola base de código y desplegar en varios SO con cambios mínimos.}~\cite{qt_wiki, qt_framework, lemberg, businesscloud, qt_history}. Su madurez (KDE, industria) y evolución de licenciamiento lo posicionan como solución robusta para aplicaciones científicas e industriales~\cite{qt_framework, qt_history}.

\subsection{Principios fundamentales de Qt}
Qt extiende C++ mediante el \emph{Meta-Object Compiler} (moc)\footnote{moc: preprocesador que genera metainformación para \emph{signals}/\emph{slots}, introspección y dispatch dinámico.}~\cite{qt_wiki}. El mecanismo \emph{signals–slots} implementa un patrón observador fuertemente tipado y desacoplado para programación dirigida por eventos~\cite{qt_mit_signals}. La arquitectura modular distingue \emph{Essentials} (Qt Core/GUI/Multimedia/Network/Quick/SQL) y \emph{Add-Ons} (OpenGL/Wayland/Sensors/WebView/Safe Renderer/SCXML), permitiendo incluir sólo lo necesario~\cite{qt_framework}.

\subsection{Widgets, layouts y Qt Quick}
La construcción clásica usa \emph{widgets} y \emph{layouts} (\texttt{QVBoxLayout}, \texttt{QHBoxLayout}, \texttt{QGridLayout}) para interfaces responsivas~\cite{businesscloud, tutorialspoint_pyqt}.\ \emph{Qt Quick} y QML\footnote{QML:\ lenguaje declarativo con JavaScript embebido para UI reactivas y animadas.} ofrecen un enfoque declarativo moderno, integrable con lógica C++/Python cuando se requiere rendimiento~\cite{qt_wiki, qt_for_python}.

\subsection{Licenciamiento y versiones}
Qt se distribuye con doble modelo (GPL/LGPL y comercial)~\cite{qt_wiki}. Qt~5 (2012) introdujo modularidad/QPA y Qt Quick~2; Qt~6 (2020) continúa la modernización; versiones LTS están disponibles principalmente para clientes comerciales~\cite{qt_framework, qt_history, qt_wiki, lemberg}.

\subsection{Aplicaciones típicas}
Qt se usa en escritorio, móvil y embebidos (automoción, salud, aeroespacial, automatización, consumo)~\cite{lemberg, qt_wiki}. Casos conocidos: Google Earth, Skype, VirtualBox, KDE, Maya, Telegram~\cite{qt_use_cases}. En computación científica: visualización, front-ends de laboratorio, GUIs de simulación y \emph{Qt Quick 3D Physics} para cuerpos rígidos~\cite{qt_quick, ontosight_pyqt_basics}.

\subsection{Ventajas y desventajas de Qt}
\textbf{Ventajas}: portabilidad real, ecosistema amplio (UI, red, multimedia, 3D), rendimiento nativo C++, documentación y comunidad sólidas~\cite{qt_framework, lemberg, businesscloud}. \\
\textbf{Desventajas}: curva de aprendizaje (C++/\emph{signals–slots}), coste de licencias comerciales, posible sobrecarga en apps muy pequeñas/ultra-embebidas~\cite{qt_wiki, itsupplychain, lemberg}.

\subsection{Introducción a PyQt}
PyQt son \emph{bindings} de Python para Qt, mantenidos por Riverbank (desde 1998, generados con SIP), con $>$1000 clases expuestas~\cite{pyqt_wiki}.\ \emph{Qt for Python} (PySide6) es la alternativa oficial de The Qt Company; la elección suele depender de licencias (PySide tiende a LGPL;\ PyQt GPL o comercial)~\cite{qt_for_python, tutorialspoint_pyqt}.

\subsection{Principios fundamentales de PyQt}
PyQt expone módulos (\texttt{QtCore}, \texttt{QtGui}, \texttt{QtWidgets}, \texttt{QtNetwork}, \texttt{QtSql}) y preserva el modelo \emph{signals–slots} en Python para GUIs reactivas~\cite{tutorialspoint_pyqt, businesscloud}. Integra con Qt Designer (\texttt{.ui} \textrightarrow{} \texttt{pyuic}) para prototipado rápido~\cite{lemberg, tutorialspoint_pyqt}.

\subsection{Aplicaciones típicas de PyQt (perfil IA)}
GUIs multiplataforma para workflows de IA/ML:\ paneles de entrenamiento e inferencia, control de simulaciones, anotación/etiquetado, visores de datos e imágenes, y front-ends que integran PyQtGraph/Matplotlib~\cite{ontosight_pyqt_basics, qt_for_python}. Útil como capa de interacción para motores numéricos (C++/CUDA) y pipelines científicos.

\subsection{Ventajas y desventajas de PyQt}
\textbf{Ventajas}: productividad de Python + potencia de Qt, multiplataforma, ecosistema de widgets/gráficos/red/BD y soporte de diseño visual~\cite{ontosight_pyqt_basics, tutorialspoint_pyqt, lemberg}. \\
\textbf{Desventajas}: licenciamiento (GPL o comercial; no LGPL en PyQt)~\cite{pyqt_wiki}; posibles fallos duros por \emph{wrapping} C++; curva mayor que Tkinter; documentación centrada en C++ requiere adaptación al entorno Python~\cite{gfg_pyqt_vs_tkinter, itsupplychain}.
