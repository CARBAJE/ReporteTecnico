\section{Algoritmos Genéticos (AGs) Simples Mono-objetivo mediante \texttt{pymoo}}
\label{sec:ags_simples_pymoo}% chktex 24

\subsection{Fundamentos de los AGs canónicos}
\label{subsec:fundamentos_ags}% chktex 24
Los \textbf{Algoritmos Genéticos (AGs)} son metaheurísticas de \textbf{computación evolutiva} que optimizan una \emph{población} de soluciones con tres operadores: \textbf{selección} (mayor probabilidad para mayor aptitud), \textbf{cruce} (recombinación de padres) y \textbf{mutación} (pequeñas perturbaciones para mantener diversidad). El \emph{AG canónico} usaba codificación binaria, ruleta, cruce de un punto y mutación por bit; hoy se emplean variantes robustas para variables continuas y problemas \emph{no lineales/no diferenciables} con múltiples óptimos locales.

\subsection{Arquitectura modular de \texttt{pymoo}}% chktex 24
\label{subsec:arquitectura_pymoo}
\texttt{pymoo} desacopla \textbf{problema}, \textbf{algoritmo} y \textbf{operadores}:
\begin{itemize}
  \item \texttt{pymoo.core.problem}: define función objetivo, $n\_var$, y límites \texttt{xl}/\texttt{xu}.
  \item \texttt{pymoo.algorithms}: incluye \texttt{GA} para mono-objetivo.
  \item \texttt{pymoo.operators}: \texttt{sampling}, \texttt{selection}, \texttt{crossover}, \texttt{mutation}.
  \item \texttt{pymoo.termination}: criterios de parada (p.\,ej., \texttt{(``n\_gen'', 100)}).
  \item \texttt{pymoo.optimize}: \texttt{minimize~()} orquesta la ejecución.
\end{itemize}

\subsection{AG mono-objetivo en \texttt{pymoo}}% chktex 24
\label{subsec:implementacion_ga}
La clase \texttt{pymoo.algorithms.soo.nonconvex.ga.GA} implementa un GA para \emph{Single-Objective Optimization} (incluye funciones no convexas).\ \textbf{Parámetros clave} de \texttt{GA~(\dots)}:
\begin{itemize}
  \item \texttt{pop\_size}: tamaño de población (exploración vs.\ costo).
  \item \texttt{sampling}: inicialización (p.\,ej., \texttt{RandomSampling}).
  \item \texttt{crossover}: recombinación (p.\,ej., \texttt{SBX}\footnote{SBX:\ \emph{Simulated Binary Crossover}; $\eta$ controla cercanía de descendientes a los padres.} para continuas; \texttt{SinglePointCrossover} para binarias).
  \item \texttt{mutation}: perturbación (p.\,ej., \texttt{PolynomialMutation}\footnote{Mutación polinomial (PM): distribución controlada por $\eta$; $\eta$ alto $\Rightarrow$ pasos pequeños.} para continuas; \texttt{BitflipMutation} para binarias).
  \item \texttt{eliminate\_duplicates}: evita individuos idénticos (más diversidad; mayor costo).
\end{itemize}

\paragraph{Flujo de trabajo.}
(1) Definir \texttt{Problem}; (2) instanciar \texttt{GA}; (3) ejecutar \texttt{minimize~(problem, algorithm, termination)}; (4) extraer \texttt{res.X} (mejor decisión) y \texttt{res.F} (mejor objetivo).

\subsection{Operadores y terminación}
\begin{itemize}
  \item \textbf{Selección}: torneo (controla presión selectiva) o ruleta.
  \item \textbf{Cruce}: \texttt{SBX} para continuas; combina y explora alrededor de padres.
  \item \textbf{Mutación}: \texttt{PolynomialMutation} para mantener diversidad y escapar de óptimos locales.
  \item \textbf{Reemplazo/elitismo}: preservar el mejor individuo entre generaciones.
  \item \textbf{Criterios de parada}: generaciones, convergencia, tiempo, etc.
\end{itemize}

\subsection{Ejemplo mínimo con \texttt{GA}}
Minimizar $f(\mathbf{x})=\sum_i x_i^2$ con límites $[-5,5]$:
\begin{listing}[htbp]
\begin{minted}[linenos,breaklines,breakanywhere]{python}
import numpy as np
from pymoo.core.problem import Problem
from pymoo.algorithms.soo.nonconvex.ga import GA
from pymoo.operators.sampling.rnd import RandomSampling
from pymoo.operators.crossover.sbx import SBX
from pymoo.operators.mutation.pm import PolynomialMutation
from pymoo.optimize import minimize

# 1) Definir el problema
class MyProblem(Problem):
    def __init__(self):
        # 2 variables (n_var=2), 1 objetivo (n_obj=1), 0 restricciones; límites [-5, 5]
        super().__init__(n_var=2, n_obj=1, n_constr=0, xl=-5, xu=5)

    def _evaluate(self, x, out, *args, **kwargs):
        out["F"] = np.sum(x**2, axis=1)

problem = MyProblem()

# 2) Instanciar el algoritmo
algorithm = GA(
    pop_size=20,
    sampling=RandomSampling(),
    crossover=SBX(prob=0.9, eta=15),
    mutation=PolynomialMutation(prob=0.1, eta=20),
    eliminate_duplicates=True
)

# 3) Ejecutar (100 generaciones)
res = minimize(problem, algorithm, ("n_gen", 100), verbose=False)

# 4) Resultado
print("Mejor X:", res.X)
print("Mejor F:", res.F)
\end{minted}
\caption{Optimización mono-objetivo con \texttt{pymoo::GA}. \emph{Nota}: \texttt{minted} requiere compilar con \texttt{-shell-escape}.}
\label{lst:pymoo_example_revised}
\end{listing}
