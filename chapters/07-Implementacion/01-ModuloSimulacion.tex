\section{Módulo de Simulación}% chktex 24
\label{cap:bitacora-implementacion}

\subsection{Introducción}
Este capítulo documenta de forma técnica y reproducible el \emph{Módulo de Simulación} empleado para estudiar dinámicas gravitacionales de dos y tres cuerpos mediante REBOUND, así como la estimación del exponente de Lyapunov (mLCE) a partir de trayectorias numéricas. La versión actual simplifica la arquitectura eliminando el antiguo \texttt{dynamics.py}; el cálculo del campo vectorial y las derivadas variacionales se delega directamente en la API oficial de REBOUND, lo que reduce el mantenimiento y garantiza consistencia con el motor de integración. Además, cada integración queda instrumentada con \texttt{time\_block} y \texttt{time\_section} para nutrir la telemetría interna y asociar métricas de desempeño con los candidatos evaluados desde el módulo lógico.

\subsection{Arquitectura de Alto Nivel}
El módulo se divide en tres componentes principales:
\begin{enumerate}
    \item \textbf{Adaptador de dinámica gravitacional (\texttt{rebound\_adapter.py})}: encapsula la creación y propagación de simulaciones usando REBOUND, valida entradas y etiqueta cada paso de integración con \texttt{time\_block} para su registro.
    \item \textbf{Estimación de Lyapunov (\texttt{lyapunov.py})}: calcula el exponente máximo a partir de una simulación REBOUND mediante las funciones MEGNO/\texttt{lyapunov()}, aceptando diccionarios de contexto y propagando metadatos de telemetría (\texttt{timing\_meta}) hacia el sistema de métricas global.
    \item \textbf{Inicialización del paquete (\texttt{\_\_init\_\_.py})}: expone una API controlada para importar las clases principales sin filtrar implementaciones internas.
\end{enumerate}

\subsection{Stack tecnológico}
\begin{itemize}
    \item \textbf{Python 3.10+} como lenguaje principal.
    \item \textbf{NumPy} para manipulación matricial y almacenamiento de trayectorias discretas.
    \item \textbf{REBOUND} como integrador N-cuerpos (p.ej.\ \texttt{WHFast}, \texttt{IAS15}) y proveedor de las rutinas MEGNO/variacionales.
\end{itemize}

    def setup_simulation(
        self,
        masses: Iterable[float],
        r0: Iterable[Iterable[float]],
        v0: Iterable[Iterable[float]],
        move_to_com: bool = True,
    ) -> Any:
        try:
            import rebound  # type: ignore
        except Exception as e:
            raise ImportError(
                "rebound is required for ReboundSim. Use --install-hint for help."
            ) from e

        mass_tuple = tuple(float(m) for m in masses)
        n_bodies = len(mass_tuple)

            raise ValueError("ReboundSim soporta entre 2 y 3 cuerpos en la configuracion base.")

        def _normalize(
            vecs: Iterable[Iterable[float]], name: str
        ) -> Tuple[Tuple[float, float, float], ...]:
            out: list[Tuple[float, float, float]] = []
            for idx, vec in enumerate(vecs):
                try:
                    x, y, z = vec
                except Exception as exc:
                    raise ValueError(f"{name}[{idx}] debe proporcionar tres componentes (x, y, z).") from exc
                out.append((float(x), float(y), float(z)))
            if len(out) != n_bodies:
                raise ValueError(f"{name} debe contener exactamente {n_bodies} vectores.")
            return tuple(out)

        pos_tuple = _normalize(r0, "r0")
        vel_tuple = _normalize(v0, "v0")

        sim = rebound.Simulation()
        sim.G = self.G
        sim.integrator = self.integrator

        for idx in range(n_bodies):
            sim.add(
                m=mass_tuple[idx],
                x=pos_tuple[idx][0],
                y=pos_tuple[idx][1],
                z=pos_tuple[idx][2],
                vx=vel_tuple[idx][0],
                vy=vel_tuple[idx][1],
                vz=vel_tuple[idx][2],
            )
        if move_to_com:
            sim.move_to_com()
        return sim

    def integrate(self, sim: Any, t_end: float, dt: float) -> Any:
        """Integra el sistema y devuelve la trayectoria como arreglo numpy [pasos, cuerpos, 6]."""
        import numpy as _np

        if not hasattr(sim, "particles"):
            raise ValueError("Se esperaba una instancia de rebound.Simulation.")

        sim.dt = dt
        steps = max(1, int(_np.floor(t_end / dt)))
        n_bodies = len(sim.particles)
        traj = _np.zeros((steps, n_bodies, 6), dtype=float)
        base_t = sim.t if hasattr(sim, "t") else 0.0
        for i in range(steps):
            t_target = base_t + (i + 1) * dt
            with time_block(
                "simulation_step",
                batch_id=i,
                extra={"dt": dt, "t_target": t_target, "n_bodies": n_bodies},
            ):
                sim.integrate(t_target)
                for j, p in enumerate(sim.particles):
                    traj[i, j, 0] = float(p.x)
                    traj[i, j, 1] = float(p.y)
                    traj[i, j, 2] = float(p.z)
                    traj[i, j, 3] = float(p.vx)
                    traj[i, j, 4] = float(p.vy)
                    traj[i, j, 5] = float(p.vz)
        return traj
\end{minted}

\subsection{\texttt{lyapunov.py} \- Estimación del Exponente de Lyapunov}
\paragraph{Descripción general}
La clase \texttt{LyapunovEstimator} computa el exponente de Lyapunov máximo apoyándose exclusivamente en la ruta MEGNO provista por REBOUND. La estimación se encuentra decorada con \texttt{time\_section} para medir latencias y acepta tanto simulaciones vivas como diccionarios con metadatos (\texttt{sim}, \texttt{dt}, \texttt{t\_end}, \texttt{masses}, \texttt{timing\_meta}). Si la API de REBOUND no está disponible o falla, el método retorna un registro de error estructurado propagando la causa.

\subsubsection{\texttt{class LyapunovEstimator}}
\paragraph{Propósito} Calcular el mLCE a partir de un contexto REBOUND configurado con \texttt{ReboundSim} u otra fuente compatible, propagando metadatos de telemetría para que el módulo lógico pueda correlacionar resultados.

    def _mlce_with_context(
        self, ctx: Any, window: float, timing_meta: Optional[Dict[str, Any]] = None
    ) -> Tuple[float, Optional[Any], Dict[str, Any]]:
        import numpy as _np

        try:
            import rebound  # noqa: F401
        except Exception:
            raise ValueError("REBOUND no esta instalado")

        if ctx is None:
            raise ValueError("Se requiere una simulacion o contexto discreto para estimar Lyapunov")

        if isinstance(ctx, dict) and "sim" in ctx:
            sim = ctx["sim"]
            dt = float(ctx.get("dt", 0.5))
            t_end = float(ctx.get("t_end", window))
            masses_ctx = ctx.get("masses")
        else:
            sim = ctx
            dt = 0.5
            t_end = window
            masses_ctx = None

        if masses_ctx is not None:
            masses = tuple(float(m) for m in masses_ctx)
        else:
            masses, _, _ = self._extract_rebound_state(sim)

        if dt <= 0.0:
            raise ValueError("dt debe ser positivo para el Lyapunov discreto")

        steps = max(1, math.ceil(t_end / dt)) if t_end is not None else 1

        if resolved_meta is None and isinstance(ctx, dict):
            candidate_meta = ctx.get("timing_meta")

                resolved_meta = candidate_meta

        lam, info = self._mlce_rebound_variational(
            sim, dt=dt, steps=steps, timing_meta=resolved_meta
        )
        meta = {"steps": steps, "dt": dt, "n_bodies": len(masses), "masses": masses}
        if info:
            meta.update(info)
        meta.setdefault("impl", "rebound_megno")
        return lam, None, meta

\vfill
\textbf{Propósito.} Ejecutar la ruta variacional de REBOUND (MEGNO + \texttt{lyapunov~()}) y empaquetar los metadatos asociados, propagando \texttt{timing\_meta} hacia la telemetría y etiquetando cada paso de integración con \texttt{time\_block}.

    def _mlce_rebound_variational(
        self, sim: Any, dt: float, steps: int, timing_meta: Optional[Dict[str, Any]] = None
    ) -> Tuple[float, Dict[str, Any]]:
        if not hasattr(sim, "particles"):
            raise RuntimeError("Invalid REBOUND Simulation provided")
        try:
            steps = max(1, int(steps))
            sim.dt = dt
            base_t = getattr(sim, "t", 0.0)

            meta = timing_meta or {}
            epoch = int(meta.get("epoch", -1))
            batch_id = int(meta.get("batch_id", -1))
            individual_id = int(meta.get("individual_id", -1))

            sim.init_megno()
            for i in range(steps):
                t_target = base_t + (i + 1) * dt
                with time_block(
                    "simulation_step",
                    epoch=epoch,
                    batch_id=batch_id,
                    individual_id=individual_id,
                    extra={"step": i, "dt": dt, "t_target": t_target},
                ):
                    sim.integrate(t_target)

            megno_val: Optional[float]
            megno_val = None
            try:
                megno_val = float(sim.calculate_megno())
            except AttributeError:
                megno_val = None

            lam_val = float(sim.lyapunov())
            info: Dict[str, Any] = {"impl": "rebound_megno"}
            if megno_val is not None:
                info["megno"] = megno_val
            return lam_val, info
        except AttributeError as exc:
            raise RuntimeError("REBOUND MEGNO API no disponible") from exc
        except Exception as e:
            raise RuntimeError(f"REBOUND MEGNO path failed: {e}")

\subsection{\texttt{\_\_init\_\_.py} \- API del Paquete}

El archivo \texttt{\_\_init\_\_.py} expone una interfaz pública compacta para importar las clases clave del módulo. Con la eliminación de \texttt{dynamics.py}, la API queda reducida a \texttt{ReboundSim} y \texttt{LyapunovEstimator}, evitando fugas de implementaciones internas.

\begin{listing}[H]
\caption{Bloque de código de \texttt{\_\_init\_\_.py}}
\begin{adjustbox}{max width=\textwidth}
\begin{minipage}{\textwidth}
\begin{minted}[fontsize=\small, breaklines, breakanywhere]{python}
"""
Capa de simulacion que encapsula REBOUND y el calculo del exponente de Lyapunov.
"""

from .rebound_adapter import ReboundSim  # noqa: F401
from .lyapunov import LyapunovEstimator  # noqa: F401

__all__ = ["ReboundSim", "LyapunovEstimator"]


if __name__ == "__main__":
    print("Componentes disponibles:", __all__)
\end{minted}
\end{minipage}
\end{adjustbox}
\end{listing}

from two_body.simulation import ReboundSim, LyapunovEstimator
\end{minted}
